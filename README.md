# Между строк · самостоятельный кодекс 2.0

Расширение SillyTavern, которому больше не нужны «Внешние блоки».
Сохраняет статьи мира, пояснения под сообщениями, поиск, избранное, личные заметки,
редактирование и удаление статей и художественных страниц, вопросы «Что такое…?»
и генератор «Голоса мира».

## Установка

В SillyTavern откройте «Расширения» → «Установить расширение» и вставьте адрес:

```text
https://github.com/huareyu/between_lines
```

После установки обновите страницу через Ctrl+F5. Расширение рассчитано на
SillyTavern 1.18.0 со штатным менеджером профилей подключения.

Для ручной установки склонируйте репозиторий в
`public/scripts/extensions/third-party/between_lines` вашей Tavern.
Зависимости npm устанавливать не требуется: готовые `runtime.js` и CSS уже включены.

В «Расширениях» появится «Между строк · Кодекс»: включение, подключение и открытие.
Открыть кодекс можно также через волшебную палочку или `/between-lines`.
Выбор подключения доступен и в настройках самого кодекса. Используются штатные
профили менеджера подключений Tavern; главное подключение чата не переключается.
Настраиваются профиль, лимит ответа и температура. Профиль применяется к сбору,
вопросам и художественным записям. Можно использовать chat и text completion
профили, поддерживаемые менеджером Tavern, включая его пресеты и серверные ключи.
Если профиль удалён или не выбран, расширение попросит выбрать его, без подмены.

## Сохранение данных и переход с блоков

Хранилище совместимо с предыдущей версией: `message.extra.between_lines_v1`
и копии каждого свайпа, `chatMetadata.between_lines_preferences_v1` для языка,
источников, заметок и избранного. Существующие статьи доступны сразу без импорта.
Профиль старого сборщика наследуется по точному совпадению имени, затем сохраняется
по ID в `extensionSettings.between_lines_extension`. Если совпадения нет, выберите
подключение вручную. Настройки языка и источников по-прежнему относятся к чату;
профиль подключения — общий для расширения.

При переходе отключаются только пять блоков «Между строк» с известными ID и
прежние загрузчики кодекса. Остальные функции «Внешних блоков» продолжают работать.
Сами блоки и чатовые данные не удаляются. При переходе с прежней версии сначала
отключите в Tavern расширение `between-lines-loader`, затем обновите страницу.
Старый загрузчик не должен работать одновременно с самостоятельным расширением.

## Запросы и источники

Все три промпта написаны на английском. Язык статьи/страницы выбирается в кодексе.
Источники: переписка, активированный лорбук и, если разрешено, общий канон
указанного фандома. Сканирование лорбука выполняется как dry run и не меняет его.
Личные заметки и избранное не отправляются в запросы. Кодекс не добавляет тексты
в основной промпт и не пишет их в сообщения чата.

Автосбор запускается после завершённого ответа персонажа, включая streaming;
прерванные генерации и повторные события не создают повторных запросов.
Открытие и запуск расширения не вызывают модель. «Что такое…?» и «Голоса мира»
генерируются только после нажатия соответствующей кнопки. Смена чата, истории,
языка или подключения защищена от применения устаревшего ответа. Ошибка сохранения
откатывает изменение; ручные правки статей защищены от перезаписи сборщиком.

## Разработка и проверки

`node build.mjs` собирает `runtime.js` и CSS. `node --test test/*.test.mjs`
проверяет хранение, источники, работу подключения и отмену запросов.
Браузерные проверки используют сервер `node test/server.mjs` на порту 4198
и Chrome с CDP на порту 9250; все модельные ответы в них заменены фикстурами.
Реальные платные запросы для проверки установки не выполняются.
